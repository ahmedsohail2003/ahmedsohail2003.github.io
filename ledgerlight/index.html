Ledgerlight

An audit platform that flags risky Government of Canada contracts and writes LLM briefs that can't make numbers up.

The problem

1.31M Government of Canada contract records are too many to review by hand, so the risky ones have to be surfaced systematically.

An LLM can draft the brief, but in an audit a single invented number is a liability.

What I built

Detection

Six SQL red-flag indicators

Parameterized rules over 1.31M contract records: non-competitive awards, single-bid competitions, amendment inflation, threshold splitting, repeat awards and buyer concentration.

MySQL · CTE · date-windowed self-join
Grounding

Briefs that can't make numbers up

Gemini drafts each brief. Every number must resolve through a JSON path into the evidence pack and match its value, and every red flag must cite an indicator that actually fired. A failing draft is re-prompted with the exact reasons, up to 3 attempts, then replaced by a deterministic brief built only from the evidence.

Gemini API · Zod · JSON paths · provenance tags
Data layer

Least privilege, enforced by MySQL grants

Three separated database identities: admin for migrations, a SELECT-only identity for everything the model touches, and an app identity that can only append to the audit log. An integration test connects as the app identity and is denied UPDATE and DELETE.

MySQL grants · integration test
Workflow

Human review board

Analysts move cases through new, under review, substantiated or dismissed. Illegal transitions are rejected with a 409, every decision needs a written justification, and each move is audit-logged.

Express · JWT · RBAC · React 19
