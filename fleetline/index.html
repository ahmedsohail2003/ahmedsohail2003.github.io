The problem

Supervising a robot fleet means watching every robot live and being able to stop any of them instantly, even as the connection drops and recovers.

Natural-language commands make that faster, but a language model can return malformed or invented output, so nothing it says should reach a robot unchecked.

What I built

Gemini API

Natural-language commands, validated

Gemini may only propose JSON against a schema. A hand-rolled validator checks every field against the live command vocabulary. Exactly one corrective re-prompt quotes the precise error back to the model; a second failure falls through to a deterministic grammar parser. Every command shows GRAMMAR or LLM provenance in the UI.

WebSockets

Live fleet stream

Real-time event streaming with exponential-backoff reconnect and subscription replay.

Canvas

60 fps map, 10 Hz sim

The map interpolates robot positions between 10 Hz simulation updates to render at 60 fps.

Safety

Emergency stops

Stop a single robot or the whole fleet, with per-robot and fleet-wide E-stop controls.

How it works

Telemetry streams up from the simulation. Model output never runs until the validator accepts it.
